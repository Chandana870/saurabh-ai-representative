# Saurabh AI Representative – Evaluation Report

## Overview

Saurabh AI Representative is an AI-powered assistant designed to answer questions about Saurabh Singh's academic background, technical skills, projects, and professional profile.

The system combines document-based knowledge retrieval with conversational interaction through both a web chatbot and a voice agent.

## Architecture

### Web Interface

* Streamlit

### Knowledge Base

* Resume PDF
* Project documentation
* Markdown knowledge files

### Retrieval System

* ChromaDB Vector Database
* Sentence Transformer Embeddings

### Voice Agent

* Vapi AI
* Published phone number interface

## Key Features

* Resume-based question answering
* Project information retrieval
* Voice interaction
* Public web deployment
* GitHub-hosted source code

## Evaluation

### Strengths

* Fast response generation
* Accurate retrieval from uploaded documents
* Voice and text interaction support
* Easy deployment and accessibility

### Limitations

* Responses depend on uploaded knowledge
* Limited reasoning beyond available documents
* Requires knowledge base updates for new information

## Future Improvements

* Real-time GitHub integration
* Multilingual support
* Interview scheduling agent
* Advanced RAG pipeline
* Analytics dashboard

## Conclusion

The project successfully demonstrates a deployable AI representative capable of answering professional queries through both chat and voice channels while maintaining a focused knowledge base.
